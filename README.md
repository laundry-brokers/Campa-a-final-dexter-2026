# Dexter Landing (Vue 3 + Bootstrap 5 + Vite)

1. Instala Node.js 18+ (https://nodejs.org)
2. Copia tus imagenes a src/assets/img/  (logo, imagen1..imagen4, cualquier extension)
3. En esta carpeta:
   npm install
   npm run dev        -> http://localhost:5173
   npm run build      -> genera /dist listo para subir al servidor
